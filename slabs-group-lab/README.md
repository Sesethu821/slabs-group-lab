## What is the Primary Role of an Operating System (OS)?
An Operating System is the main software that manages the computer hardware and software resources. 
Its primary roles are:
1.  To manage hardware - controls CPU, memory, storage and devices.
2.  To provide a user interface - allows users to interact with the computer.
3.  To manage files and processes - organizes files and runs applications.
4.  To provide security and resource management - protects data and shares resources fairly.
